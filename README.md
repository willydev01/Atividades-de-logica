# Treino de Lógica em Python

Repositório com exercícios de lógica que fiz para treinar funções, loops e listas.

## O que tem aqui
- Par ou ímpar
- Contar vogais
- Somar números pares
- Filtrar números pares

## Como usei
- Cada função tem testes no próprio arquivo
- Usei `for`, `if`, `return` e listas
